# Report Pulizie

Struttura base del progetto per la gestione dei report pulizie.

## Struttura

- `src/` logica applicativa
- `data/` dati di esempio o esportazioni
- `templates/` modelli report
- `docs/` documentazione
- `scripts/` script utili

## Avvio rapido

1. Clona il repository
2. Aggiungi qui i file del progetto
3. Esegui commit e push
