# PDF Premium — V1

## Obiettivo

Generare un PDF professionale, pulito e adatto a essere inviato al responsabile.

## Contenuto PDF

Il PDF deve includere:

- Logo azienda
- Titolo: Report Pulizia Giornaliero
- Data intervento
- Operatore
- Cliente / struttura
- Indirizzo
- Tipologia immobile
- Orario entrata
- Orario uscita
- Pausa
- Totale ore
- Attività svolte
- Anomalie
- Note operative
- Foto allegate, se presenti
- Link video esterno, se presente
- Data e ora generazione PDF

## Layout consigliato

Sezioni:

1. Header azienda
2. Dati intervento
3. Orari
4. Attività svolte
5. Anomalie
6. Note
7. Foto
8. Link video esterno
9. Footer generazione

## Foto nel PDF

Se ci sono foto:

- Mostrare foto divise per categoria
- Mostrare massimo 4/6 foto nel PDF
- Se ci sono più foto, scrivere:

“Sono presenti ulteriori foto nell’archivio digitale del report.”

Se non ci sono foto:

“Nessuna foto allegata al report.”

## Nome file

Usare:

report-pulizia-[cliente]-[data]-[operatore].pdf

## Qualità

Il PDF deve essere:

- Leggibile
- Ordinato
- Stampabile
- Professionale
- Non troppo pesante
- Funzionante da mobile e desktop
