# Anomalie e Note — V1

## Sezione anomalie

Aggiungere opzioni selezionabili:

- Nessuna anomalia
- Casa trovata molto sporca
- Presenza eccessiva di peli animali
- Presenza eccessiva di capelli
- Mancanza prodotti / materiali
- Oggetti rotti già presenti
- Zone non accessibili
- Lenzuola pulite non disponibili
- Letto non rifatto per mancanza biancheria
- Bagno in condizioni critiche
- Cucina in condizioni critiche
- Tempo insufficiente per completare tutto
- Altro

## Regola esclusione

“Nessuna anomalia” non può essere selezionata insieme ad altre anomalie.

Se l’operatore seleziona “Nessuna anomalia”:

- Deselezionare tutte le altre anomalie

Se l’operatore seleziona un’altra anomalia:

- Deselezionare “Nessuna anomalia”

## Note operative

Aggiungere campo:

- Note operatore

Il campo è opzionale.

Se compilato, deve apparire nel PDF.

## Note anomalia

Per “Altro” o anomalie importanti, consentire nota testuale opzionale.
