# Daily Cleaning Report V1 — Progetto Codex

## Obiettivo

Creare una web app mobile-first chiamata **Daily Cleaning Report V1**.

Serve a un operatore/dipendente di un’impresa di pulizie per creare velocemente un report giornaliero del lavoro svolto presso appartamenti, ville, uffici, B&B, case vacanza o altri immobili.

## Focus assoluto V1

Implementare solo:

- Login
- Ruoli operatore/admin
- Creazione report giornaliero
- Orario entrata
- Orario uscita
- Pausa
- Totale ore automatico
- Cliente/immobile
- Checklist attività svolte
- Anomalie
- Note
- Foto opzionali
- Archivio foto
- Link video esterno opzionale come semplice link/testo
- PDF premium
- Download PDF
- Stampa PDF
- Condivisione WhatsApp con messaggio precompilato
- Invio Telegram semplice, se configurato
- Invio email semplice, se configurato
- Dashboard admin semplice
- Sicurezza Supabase/RLS

## Non sviluppare nella V1

Non implementare:

- Preventivi
- Pagamenti
- Fatture
- Upload video
- Archivio video
- Player video
- Compressione video
- WhatsApp Business API
- App nativa mobile
- Gestione turni avanzata
- Magazzino prodotti
- Chat interna
- GPS obbligatorio
- Funzioni V2

## Stack tecnico

- Next.js
- React
- TypeScript
- Tailwind CSS
- Supabase
- Supabase Auth
- Supabase PostgreSQL
- Supabase Storage
- Generazione PDF
- Email semplice
- Telegram Bot opzionale
- WhatsApp link / Web Share API
- Mobile-first design

## Obiettivo UX

L’operatore deve completare un report standard da smartphone in meno di 2 minuti.
